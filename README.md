# Mario Party 4 Deluxe — native PC development build

A way to play Mario Party 4 natively with extra features and QOL changes and online support
Launch **Mario Party 4 Deluxe.exe** directly. Play.exe is an optional, limited party/practice launcher; it is not required for the normal game.

You need an official copy of **Mario Party 4's European Version** to play. This build is made for the **Rev 2** version of it.
